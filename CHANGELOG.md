# SimDesk changelog

Newest first. One line per feature, added by whichever thread builds it: thread, date (UTC), files touched. Before re-packing the shared code copy, diff it against the latest copy and make sure nothing earlier disappeared.

## 2026-11-08
- **Public home page and beta application page** (thread "Design SimDesk landing page"). Signed-out visitors now see the home page instead of the sign-in; `#/beta` is the beta application page (multi-select "How do you play" with an Other type-in, Sims tracked, what they track with now, save notes, regular-feedback note); `#/login` is the sign-in for beta testers (opens on Log in) and nothing on the public pages links to it. No Log in button, and no person's name appears on either page. Forms post to Kit only: paste the two Kit form URLs into `src/config/landing.ts` (`KIT.waitlist`, `KIT.beta`, custom fields listed there); until then they say sign-ups are not open and send nothing. Nothing is stored in Supabase. Pages are reviewed plain HTML (`src/pages/landing/home.html`, `beta.html`) with scoped CSS (`src/styles/landing.css`, wrappers `.lp` / `.lpb`) and images in `public/landing/`. Files: `src/pages/landing/{Landing.tsx,behavior.ts}`, `src/config/landing.ts`, `src/main.tsx` (routing), `src/pages/Auth.tsx` (`startLogin`), `index.html` (DM Sans and DM Mono), `_handoff/test-scripts/testlanding.cjs`. Domain not confirmed (config still says simdesk.life in `src/config/app.ts`).

## 2026-11-07
- **Household page, compact desktop layout** (thread "Rebalance the household page layout"). Desktop only, phone untouched: two even columns; Sims as rows with each Sim's net worth; Money card keeps total, class, change, chart, Household funds and Details (per-Sim breakdown stays in the Details pop-over); compact Coming up rows; "Home and lots" card with one dashed "Pick a home" row; Notes as plain text; Move Sims in is a header button and Edit household moved into the ⋯ menu; bigger hit area on the breadcrumb and Rotation icon link. Files: `src/pages/households/HouseholdPage.tsx`, `src/pages/money/Money.tsx` (`MoneyCard` `compact`, `useSimNet`), `src/pages/calendar/shared.tsx` (`ComingUp` `compact`), `src/styles/households.css`, `src/styles/money.css` (`.mny-open` width). Test: `_handoff/test-scripts/commands/testhouseholdpage.cjs` (25 checks).
- **Account page and backups** (thread "Continue SimDesk fewer-clicks work"). New Account page: name on top, Username / Email / Password rows (password change window), App settings row, Backups card, Deleted saves, Log out; Style check and "Signed in" removed. Backups are computer only (phone shows a one-line note). Download opens three choices: Backup file (.json, with Include photos, restorable), Spreadsheet (.xlsx, tabs Sims, Households, Lots, Relationships, Calendar, Clubs), Photos (.zip of JPGs named after the Sim or caption). Restore from a backup always makes a NEW save, re-uploads photos under new ids, and replaces nothing. "Last backup" is kept on the save (`SaveData.backedUpAt`). `xlsx` moved from devDependencies to dependencies (loaded only when a spreadsheet is made). New: `src/pages/account/AccountParts.tsx`, `src/lib/sync/spreadsheet.ts`, `src/lib/sync/photoZip.ts`, `src/lib/sync/export.test.ts`, `_handoff/test-scripts/testaccount.cjs` (44 checks). Changed: `src/lib/sync/backup.ts` (format 2 with photos, `readBackup`, `restoreBackup`, `lastBackupOf`), `src/lib/sync/store.ts` (`importSave`), `src/lib/saves.ts` (`backedUpAt`), `src/pages/AccountScreens.tsx`, `src/styles/auth.css` (`.acct-*`), `package.json`, `package-lock.json`.
- **Playing now: Add a day, Pause rotation, Play someone else** (same thread). Add a day lengthens only this turn (`Rotation.extra`, cleared when the next turn starts); Pause keeps one household playing with no end (`Rotation.paused`), Resume starts a fresh turn today; Play someone else is a search list on the Playing now card (tap = play now, households outside the rotation join as they start, + adds to the end of the line). New helpers `currentLength`, `addDays`, `pause`, `resume`. Files: `src/lib/rotation.ts` (+ test), `src/pages/rotation/Rotation.tsx` (`SwitchDialog`), `src/styles/rotation.css`, `src/components/CommandBar.tsx` (uses `currentLength`), `_handoff/test-scripts/testrotation.cjs` (now 70 checks). The Quick actions "Play someone else" tile on phone still opens the command picker; point it at `SwitchDialog` if wanted.
